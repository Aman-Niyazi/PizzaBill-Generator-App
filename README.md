🍕 Pizza Bill Generator App

A simple Java-based desktop application built using Java Swing that allows users to select different pizza options and toppings, then dynamically calculates and displays the total bill.

This project demonstrates core Java programming concepts, including GUI development, event handling, and Object-Oriented Programming (OOP).

✨ Features
Interactive graphical user interface built with Java Swing
Select different pizza options
Add additional toppings
Real-time bill calculation
Displays the total cost based on user selections
Clean and modular code structure
Easy to understand and modify
🛠️ Tech Stack
Language: Java
GUI Framework: Java Swing
Architecture: Standalone Desktop Application
Programming Concepts: Object-Oriented Programming (OOP)
🚀 How to Run
Clone the repository:
git clone https://github.com/Aman-Niyazi/PizzaBill-Generator-App.git
Open the project in an IDE such as IntelliJ IDEA or Eclipse.
Locate and run the main Java class:
Pizza.java
Use the graphical interface to select pizza options and generate the bill.
